# Amazon Mobile Cart Automation

## Description
This repository contains a Python script that uses Selenium to automate the process of adding the first three mobiles from the mobile category on Amazon.com to the cart.

## Setup Instructions

1. Install Python and ensure it is added to your system PATH.
2. Install Selenium using pip:
   ```
   pip install selenium
   ```
3. Download the appropriate WebDriver for your browser (e.g., ChromeDriver for Google Chrome) and ensure it is in your system PATH.
4. Clone this repository and navigate to the project folder.
5. Run the script using the following command:
   ```
   python add_mobiles_to_cart.py
   ```

## Notes
- Ensure that the browser version matches the WebDriver version.
- The script is designed to handle basic scenarios and may require adjustments for specific cases or changes in Amazon's website structure.
