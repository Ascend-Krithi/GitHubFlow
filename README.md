# Automation Test Scripts

This repository contains automated test scripts for:
- Printing System API (Pytest)
- AI Agent UI Edge Cases (Selenium + Pytest)

## Structure
- `print_system/test_print_system_api.py` - API test scripts for the printing system
- `ai_agent/test_ai_agent_edge_cases.py` - Selenium-based UI edge case tests for the AI agent
